# Question Bank

Ready-to-use questions for different scenarios.

## General Technical Questions

### Scoping
1. What does "done" look like for this task?
2. What are the must-haves vs nice-to-haves?
3. Are there any explicit exclusions?
4. What is the timeline? Is it negotiable?

### Technical Constraints
1. What technology stack must be used?
2. Are there version constraints (Python 3.9+, Node 18+)?
3. Any performance requirements (latency <100ms, throughput >1000 QPS)?
4. Any resource constraints (memory <2GB, CPU cores)?

### Integration
1. Does this need to integrate with existing systems?
2. Are there API contracts to follow?
3. Any database schema constraints?
4. Authentication/authorization requirements?

### Testing & Quality
1. What is the testing strategy? Unit/Integration/E2E?
2. Are there code coverage requirements?
3. Need for load testing or stress testing?
4. Any security scanning requirements?

### Deployment
1. Where will this be deployed?
2. What's the deployment process (CI/CD)?
3. Any rollback considerations?
4. Feature flags needed?

## For Documentation Tasks

1. Who is the target audience? (beginners, experts, specific roles)
2. What is the purpose? (tutorial, reference, explanation)
3. Any style guide to follow?
4. Examples required? Code samples?
5. Diagrams needed?

## For Research/Analysis Tasks

1. What is the specific research question?
2. What is the depth expected? (high-level overview vs deep dive)
3. Any specific sources to prioritize? (official docs, academic papers)
4. Any sources to avoid? (outdated blogs, unofficial docs)
5. How should conflicting information be handled?

## For Refactoring

1. What is the motivation? (performance, readability, tech debt)
2. What is the scope? (one function, module, or entire system)
3. Are there behavioral changes allowed?
4. How comprehensive should testing be?
5. Any backward compatibility requirements?

## Warning Sign Questions

If user cannot answer these, scope is not clear enough:
- "What problem are we solving?"
- "How will we know if this is successful?"
- "Who will use this?"

## Questions to Ask Yourself

Before presenting analysis:
- Have I verified all technical claims?
- Are there any assumptions I'm making?
- What could go wrong with my proposed approach?
- Is there a simpler way to achieve the goal?
